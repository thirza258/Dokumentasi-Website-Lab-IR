	This website documentation was developed in response to the need for a new website, as the previous one had become outdated in terms of both database structure and technology. The purpose of this documentation is to provide comprehensive information about the development of the new website, starting from the background and requirements analysis to the implementation, testing, and usage guidelines. The Waterfall method was applied in defining the website development process through systematic and sequential stages. The result of this process is a new Django-based website that meets the identified user requirements. This documentation is intended to serve as a guide for both users and future developers in managing and further developing the website.
